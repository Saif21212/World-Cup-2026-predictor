# FIFA World Cup 2026 Predictor

A match prediction model for the 2026 FIFA World Cup built from scratch in Python. It ingests historical international football results dating back to 1872, computes Elo ratings for every national team, and will use those ratings as the foundation for match-outcome probability estimates. The project grows deliberately — starting with plain vanilla Elo, then layering in home advantage, tournament weighting, and eventually a full prediction pipeline.
